  Create only a missing scaffold index so Capacitor completes its initial platform sync, without replacing compiled web assets or manufacturing a release manifest. Existing platform directories are synchronized on retry instead of failing a second add. Native initialization uses the current pinned Devices packages in the freshly built CLI.
